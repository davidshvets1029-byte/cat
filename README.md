# Сайт про котів

## Опис проекту
Цей сайт присвячений домашнім улюбленцям — котам. Тут зібрані цікаві факти, історичні згадки та легенди про цих тварин, а також доступна форма зворотного зв'язку.

## Структура сайту
- index.html — Головна сторінка з фактами про тваринку та формою зв'язку
- story.html — Історії та легенди про котів

## Використані технології
- HTML5
- Семантична розмітка (header, nav, main, section, figure)
- Форми з HTML5 валідацією (required, minlength, email)
